SUPPORT & TROUBLESHOOTING
================================================================================

COMMON ISSUES:

1. Compilation fails with "unit not found"
   → Ensure all .pas files in same directory
   → Check PATH includes current directory
   → Verify FPC installation

2. Tests fail with memory errors
   → Check free disk space
   → Run: make clean && make build
   → Verify compiler version (3.2.0+)

3. Descriptor mismatch with Rust
   → Verify struct alignment ({$PACKRECORDS C})
   → Check sizeof(TTensorDescriptor) = sizeof(CTensorDescriptor)
   → Use CompareDescriptors() oracle to debug

4. Generation overflow
   → Uses uint32 (4 billion+ generations)
   → Should never overflow in practice
   → Monitor via GetGeneration() function

DEBUGGING:
  • Use gdb for source-level debugging
  • Enable verbose output in test cases
  • Call VerifyGovernanceLemmas() after operations
  • Use DebugDescriptor() utilities in source
  • Check generation consistency

PERFORMANCE ANALYSIS:
  • Compile with -g for debug symbols
  • Profile with perf/flamegraph
  • Use timing instrumentation in tests
  • Check memory usage with valgrind
