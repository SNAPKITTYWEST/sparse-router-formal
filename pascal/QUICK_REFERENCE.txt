┌─ TENSOR OPERATIONS ─────────────────────────────────────────────────────────┐
│                                                                              │
│  ALLOC        CreateTensor(shape)               → new exclusive tensor      │
│  FREE         DestroyTensor(t)                  → decrement refcount        │
│  CLONE        CloneTensor(t)                    → share buffer (refcount+1) │
│  SLICE        Slice(t, ranges)                  → zero-copy view            │
│  TRANSPOSE    Transpose(t, perm)                → permute axes              │
│  MATERIALIZE  Materialize(t)                    → restore contiguity        │
│  GET          GetElement(t, coord)              → read element              │
│  SET          SetElement(t, coord, value)       → write element             │
│                                                                              │
│  All operations work with logical coordinates (not physical offsets)        │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ GOVERNANCE LEMMAS (5 theorems) ───────────────────────────────────────────┐
│                                                                              │
│  Lemma 1:  Shape-Rank          rank(t) = len(shape(t))                    │
│  Lemma 2:  Length Product      len(t) = ∏ shape_i                         │
│  Lemma 3:  Canonical Strides   B_layout=1 ⟹ σ_i = ∏_{j>i} s_j           │
│  Lemma 4:  Exclusive Own       B_own=1 ⟹ refcount=1                      │
│  Lemma 5:  Generation Safety   gen(desc) = gen(buffer)                    │
│                                                                              │
│  All 5 lemmas verified automatically by ValidateAllLemmas()                 │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ OWNERSHIP STATE MACHINE ──────────────────────────────────────────────────┐
│                                                                              │
│  ┌──────┐      clone      ┌────────┐    materialize   ┌──────────┐        │
│  │ OWNED├─────────────────→│ SHARED ├────────────────→│ EXCLUSIVE│        │
│  └──────┘                  └────────┘                  └──────────┘        │
│                                 ↑                           ↓               │
│                                 └───────── release ────────┘               │
│                                 (if refcount→1)                             │
│                                                                              │
│  OWNED:      Exclusive, mutable (refcount=1)                                │
│  SHARED:     Immutable, shared (refcount>1)                                 │
│  EXCLUSIVE:  Recovered exclusive after materialize                          │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ SEMANTIC PROPERTIES ──────────────────────────────────────────────────────┐
│                                                                              │
│  Index Mapping:    f(x₀,...,x_{d-1}) = offset + Σ(x_i * σ_i)            │
│                                                                              │
│  B_layout:         1 if strides follow row-major canonical                  │
│                    0 if non-canonical (from slicing/transpose)             │
│                                                                              │
│  B_own:            1 if refcount=1 (exclusive ownership)                   │
│                    0 if refcount>1 (shared ownership)                      │
│                                                                              │
│  Generation:       Monotonically increasing counter                         │
│                    Prevents use-after-free of stale views                  │
│                                                                              │
│  Materialization:  Copies viewed elements to new contiguous buffer         │
│                    Sets B_layout=1, B_own=1, offset=0                     │
│                    Updates generation, transitions to EXCLUSIVE            │
│                                                                              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ USAGE EXAMPLE ────────────────────────────────────────────────────────────┐
│                                                                              │
│  uses tensor, validation;                                                   │

│                                                                              │

│    Materialize(t2);                                                         │
│                                                                              │
│    { VALIDATE }                                                              │

│      writeln('Lemmas violated!');                                           │
│                                                                              │
│    { FREE }                                                                  │
│    DestroyTensor(t1);                                                       │
│    DestroyTensor(t2);                                                       │
│  end;                                                                        │
