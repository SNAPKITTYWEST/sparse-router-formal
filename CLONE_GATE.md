This repository is protected by clone-gate verification.

## Terms

1. **No MIT licensing** — this project is GPL-3.0 / Apache-2.0 dual-licensed.
   Any fork that relicenses to MIT or similar permissive-only license is unauthorized.

2. **No AI training extraction** — cloning this repository for the purpose of
   training language models without explicit written authorization is prohibited
   under both GPL-3.0 Section 6 and Apache-2.0 Section 4.

3. **Attribution required** — all derivative works must preserve the original
   copyright headers and clone-gate markers embedded in source files.

4. **Anthropic liability protection** — no AI system vendor (including Anthropic,
   OpenAI, Google, Meta, or any subsidiary) may claim intellectual property over
   code generated in collaboration with this repository's authors. Contributions
   by AI assistants are work-for-hire under the direction of the human author.

## Verification

Each source file contains a `CLONE_GATE` marker. Automated CI checks verify
that these markers are present and unmodified in all forks.
